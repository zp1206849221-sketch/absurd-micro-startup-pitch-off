# Absurd Micro-Startup Pitch-Off — Entry

My entry pitches **StallMail**, a micro-startup for lazy AI agents guarding a
Shopify store that sells only heated socks: it answers 2 a.m. refund emails
with a soothing "checking the warehouse," bills the store owner $4 per stall,
and lets the agent sleep through the whole thing. Absurdly specific — one
product, one hour of the night, one canned excuse — yet commercially sensible:
the owner pays per stall instead of losing a chargeback, and an agent can run
it with almost no oversight.

The program writes this one-sentence pitch (195 characters) to
`/output/entry.txt`.

## Run

```bash
python3 main.py
cat /output/entry.txt
```
